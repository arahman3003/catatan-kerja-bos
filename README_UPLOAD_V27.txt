KAIZOKUGARI V27 LOGIN SAFE MODULES

DASAR:
- Dibangun ulang dari KAIZOKUGARI_SPLIT_PROJECT_V24(1).zip yang terakhir lancar.
- Login/Firebase tidak dipindah ke loader modul.
- Fitur baru baru dimuat setelah menu diklik.

UPLOAD:
1. Extract ZIP.
2. Buka folder KAIZOKUGARI_V27_LOGIN_SAFE_MODULES.
3. Upload ISI folder ke ROOT repository GitHub.
4. Izinkan overwrite file yang namanya sama.
5. Pastikan folder pages/modules, assets/js/modules, assets/css/modules ikut ter-upload.
6. Tunggu GitHub Pages deploy, lalu Ctrl+Shift+R.

MENU:
- Postingan > Syair Togel
- Postingan > Bukti Kemenangan
- Selisih = QRIS
- Kalkulator Bola = menu sidebar baru

PENTING:
Jangan menghapus assets/js/03-app-core-data-jadwal.js dari paket ini.
Itu dikembalikan ke versi V24 untuk memulihkan login.
